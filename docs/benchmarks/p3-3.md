# IE P3.3 Performance Baseline

This benchmark measures the IE runtime with the Actus `std::time` monotonic
clock. It is kept separate from correctness tests.

## Fixture

- Source: `benchmarks/ie_p3_3.act`
- Arena: 64 minicolumn slots
- Workload: 10,000 iterations per measurement
- Coincidence input: `mask_low=1u64`, `mask_high=0u64`
- Forwarding topology: one source with eight configured axons
- Runtime: `std`
- Target: `host`
- Floating point: disabled by `verify_no_float_ir = true`

## Run

```bash
actus build benchmarks/ie_p3_3.act \
  --strict \
  --emit exe \
  -o /tmp/twin-e-ie-p3-3

/tmp/twin-e-ie-p3-3
```

The executable reports elapsed monotonic nanoseconds for coincidence scoring,
eight-axon forwarding, free-list allocation/deallocation, and one complete
wavefront step. Record the compiler binary digest, host target, build profile,
and captured output with each baseline result.

## Acceptance

- The fixture builds with strict checking.
- The generated native IR passes the zero-float audit.
- The executable exits with status `0`.
- Each reported duration is a non-negative `u64` elapsed interval.
